Background

The linkage of diet with weight management has drawn some interest in recent years, with the spiraling prevalence of obesity and related metabolic conditions in many parts of the world. Though there is documented evidence that what we consume greatly influences body weight, much about how changes in eating habits contribute differently toward weight is still highly elusive. While some reveal striking weight change with either an improvement or deterioration in diet, others seem to be unaffected by similar alterations. These observations raise the following questions: whether same, better, or worse eating behavioral changes-represent weight change uniformly across individuals.

Now for the true purpose of this analysis we want to know if each eating change has the same effect on weight or if at least one has a different effect. And for us to do this we just need to know if all groups belong to the same sampling distribution. \[ H_0:\text{ (All eating change groups belong to the same sample distribution)}\\ \] \[ H_0:\text{ (At least one group is stochastically different than the others)}\\ \]

\[ α=0.05 \]

kruskal.test(weight~eating_changes_coded,data=new) %>% pander()

Conclusion

The results of the analysis shows that each of the different eating changes all have the same effect on a persons body weight, or even if the effects aren’t exactly the same the difference is too little to be considered.So if a person really wants to alter their body weights changing their eating habits wont be the only thing that will help them accomplish this.we were able to conclude this because from our analysis above we can see that the test had a p-value of 0.06115 and as compared to our significance level (0.05) we will fail to reject our null hypothesis because there is in sufficient evidence for the alternative.
